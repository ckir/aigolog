# aigolog Sub-project B1 (Ingest) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `aigolog analyze <file>... | -` reads text logs to their end, keeps every line in one new database per run, gives each record the time the log states, and prints what it ingested; `aigolog list` and `aigolog clean` show and remove the kept databases. This proves the time cases and the two-analyses case of acceptance test A2.

**Architecture:** A reader turns an input into records (`internal/record` is the plug point; `internal/reader/text` is the first reader). `internal/ingest` feeds a reader's records, in batches, to `internal/store`, which owns the database: one file per run, a lock file held for the whole run, a completion mark, the program's version, retention. Time rules live in `internal/timeparse`. Everything printed from outside goes through `internal/textsafe`. `internal/cli` wires the three commands.

**Tech Stack:** Go 1.27.4 (module floor `go 1.26.0`); `modernc.org/sqlite` v1.62.0; `golang.org/x/sys` (file locks); standard library for the rest, including `unicode/utf16` for UTF-16 and `encoding/json` for the configuration file.

**Spec:** `docs/superpowers/specs/2026-11-15-engine-and-report-design.md` (sections 7.1 "Text lines" and the common paragraph, 7.2, 7.4, 7.11, 7.12, 7.13, and A2 in section 8). The roadmap, `docs/superpowers/plans/2026-11-16-part-1-roadmap.md`, fixes the decisions that hold for all of part 1 and the row for B1; this plan repeats the ones it uses.

**The code this plan builds on exists on `main` (commit `9fbc71c`) and was read on 2026-11-16:** `internal/cli/cli.go` (`usage` at lines 21-29, `Run(args []string, stdout, stderr io.Writer) int` at line 32, the `version` case at line 41, the unknown-command case at line 54), `internal/cli/cli_test.go` (the `run` helper at line 21), `internal/store/engine.go` (`DriverName`, `EngineVersion`), `internal/exitcode/exitcode.go` (six constants, 0 to 5), `internal/buildinfo/buildinfo.go` (`var Version`), `justfile`, `go.mod` (`golang.org/x/sys v0.49.0` is a direct requirement). `internal/textsafe`, `record`, `timeparse`, `reader/text`, `config` and `ingest` do not exist yet; `internal/store` gains files and keeps `engine.go` unchanged.

**What was checked before this plan was handed over (2026-11-16, on the development machine, in throwaway folders outside the repository):**
- The year rule of design 7.2, written as the plan's Task 3 describes it, gives the expected years in all five time cases of A2 plus the one-day-slack case (the values in Task 3's tests are the program's output).
- Go's `time.Parse` finds every stamp form of Task 2's list as a prefix of a line, accepts fractional seconds written with `.` or `,`, refuses `2026-13-45` and `Feb 30`, and accepts `Feb 29` with no year; it accepts `Jan 5` as well as `Jan  5` for the layout `Jan _2`.
- SQLite settings (1,000,000 rows, rows of about 80 bytes, this machine, load not controlled, two runs each): inserting took 5.3 to 6.6 s and rewriting each row once in reverse order took 6.0 to 7.3 s; `journal_mode` MEMORY, WAL and OFF were within that spread of each other, and the database was 144 MB at the end in every case. So the plan uses the simplest setting (Task 5) and does not use WAL, which would add side files for `list` and `clean` to account for.
- **Not checked, because it cannot be done here:** anything on Windows, which is the file lock (`LockFileEx`), removing files, and every test of Tasks 5, 6 and 10 on that system. Task 10 is where the hosted Windows machines first run them.

## Global Constraints

- Targets: `linux/amd64`, `linux/arm64`, `windows/amd64`, `windows/arm64`; every build `CGO_ENABLED=0`. The suite must pass on all three hosted machines of the workflow (`ubuntu-24.04`, `windows-2025`, `windows-11-arm`).
- Third-party modules: `modernc.org/sqlite` and `golang.org/x/sys` only. No module is added. UTF-16 is decoded with `unicode/utf16`, not with `golang.org/x/text`.
- Memory must not grow with the size of the input (design 7.4): records go to disk as they are read, in batches of at most 5,000.
- Standard input cannot be read twice (design 7.3): nothing in B1 reads an input twice.
- Times are taken as written; no zone is assumed or converted (design 7.2). A stamp with no zone is stored as a wall-clock reading, carried as nanoseconds since 1970 as if the reading were UTC.
- The database is created readable and writable by its owner only (mode 0600, its folder 0700); on Windows the folder's rules apply (design 7.4).
- Nothing removes a database that a live run holds. Two analyses at the same time must not disturb each other.
- Exit codes (roadmap decision 4): `0` done, `1` failed, `2` wrong usage, `5` the store cannot be written. (`3` and `4` belong to later sub-projects.)
- Nothing printed to a terminal carries a raw control character, whatever its source (design 7.11): every name, path and error that comes from outside goes through `textsafe.Clean` before it is printed.
- Every `.go` file starts with the five lines of `source-header.txt` as `//` comments, then one empty line (the header test of `internal/repocheck` enforces this):

  ```go

  // This software is licensed under the PolyForm Noncommercial License 1.0.0.
  // You may obtain a copy of the License at:
  // https://polyformproject.org/licenses/noncommercial/1.0.0/
  ```

  A file with a `//go:build` line has the header, an empty line, the `//go:build` line, an empty line, then `package`.
- `just check` is the gate and must pass before every commit (the pre-commit hook runs part of it; the pre-push hook runs all of it).
- `go test ./...` passes with no network.
- The repository is public. No name, address or path from the development machine goes into a file or a commit message. Tests never touch the user's real cache or configuration folder: they pass a temporary folder.
- Work is on the branch `b1-ingest`, made from `main`. Commit when a task says so. **Push only when the owner says so.**
- Stop and report, without adapting, if a file this plan says does not exist already exists, if a step that should pass fails, or if a step that should fail passes. Where a step says a command fails, the reason it gives is what matters; Go's exact wording may differ.

## Review Focus

Inputs and conditions the design implies and a person would hit, each pinned by a test in the task named:

1. **A line of several megabytes with no newline, and a file with no newline at the end.** The line is kept whole; the last record is not lost (Task 4).
2. **Files written on Windows:** CRLF line ends, a UTF-8 byte-order mark, UTF-16 with a byte-order mark. They give the same records as the same text in plain UTF-8 (Task 4).
3. **A file with a NUL byte far past the first block.** The run is refused, names the source and the byte offset, and leaves no database behind (Tasks 4, 8, 9).
4. **A file whose name holds escape characters, printed by `analyze`, `list` or an error.** No raw control character reaches the terminal (Tasks 1, 9).
5. **A run killed in the middle, two runs at once, and a cleaner that runs while another run works.** The killed run's database is removed by a later run; the live one is never removed; each run ends with its own complete database (Tasks 6, 10). And an unwritable cache folder ends with exit code 5 and a message (Task 9).

## Calls this plan makes

The design leaves these to the builder (its section 13) or says "a lock held on the file is the expected way" (7.4). The second model was consulted on them before this plan was written and agreed with each (where it added to one, the table says so). None changes a goal, an acceptance test, or a decision of the roadmap.

| # | Call | Reason |
|---|---|---|
| 1 | A run takes a lock file `<name>.lock`, created exclusively, **before** it creates `<name>.db`, and holds it until it ends (`unix.Flock` on Linux, `windows.LockFileEx` on Windows). A cleaner that can take the lock knows the run is gone | The operating system releases the lock if the process is killed; the order closes the race between a cleaner and a run that is starting |
| 2 | A syslog-style stamp (no year) is stored as month, day and time of day with state "year pending"; after the last line of the source a pass over that source's records **in reverse order, read from the database,** gives each its year and writes the time in batches | Design 7.2's rule needs the end of the source first; keeping the stamps in memory would make memory grow with the input |
| 3 | A time is three columns: nanoseconds since 1970 (a stamp with no zone read as if UTC), `exact` (1 when the log states a zone or the stamp is a count), and the zone text as written | Orders and compares in SQL; the zone is shown only when the log states one |
| 4 | The layout is chosen from a sample: the first 100 non-blank lines that do **not** begin with white space, taken from the first 64 KiB. A layout fits if it parses at least half of them; the layout that parses most wins, ties to the earlier one in the list | Indented lines are continuation lines by definition and must not count against a layout |
| 5 | B1's database holds only what B1 fills: tables `meta`, `sources`, `records`. B2 adds its own tables | The database refuses another program version (design 7.4), so no migration is ever needed inside part 1 |
| 6 | SQLite runs with `journal_mode=MEMORY` and `synchronous=OFF` on one pinned connection; WAL is not used | Measured: no difference within the spread; WAL adds side files. A half-written database is never used (it stays incomplete and is removed) |
| 7 | The configuration file is JSON, in `os.UserConfigDir()/aigolog/config.json`; `AIGOLOG_CONFIG` names another file; environment variables `AIGOLOG_KEEP_DAYS`, `AIGOLOG_MAX_TOTAL_BYTES`, `AIGOLOG_CACHE_DIR` override the file; unknown keys are refused. B1 holds `keep_days` (7), `max_total_bytes` (**provisional** 1 GiB, replaced after B2 measures a database next to its log) and `cache_dir` | Design 7.13 leaves the format to the builder. No key has a flag in B1, so the order file, environment, flag has no flag step yet |
| 8 | `--format` accepts `auto` and `text`; `jsonl` and `eventxml` are refused with a message that they are not built yet | The other readers come in D and E |
| 9 | Positions: `Line` is the number of the record's first line; `Offset` and `Length` count bytes of the original input for UTF-8, and bytes of the decoded text for UTF-16; `Raw` is the record's lines with their terminators removed, joined by `\n`, invalid UTF-8 replaced by U+FFFD | Raw text is kept exactly apart from what cannot be text |
| 10 | The list of nine stamp layouts in Task 2 | "The list of layouts is left to the builder; the test logs set the bar" (7.2). It is provisional: B2's generated logs may add layouts |

  - `timeparse.Layout{Name string; Exact, YearPending bool}` (and an unexported Go layout string); `timeparse.Layouts []Layout`; `timeparse.Detect(lines []string) (Layout, bool)`; `(Layout).Parse(line string) (record.Stamp, bool)`; `timeparse.WallNanos(t time.Time) int64`.

- [ ] **Step 1: Write `internal/record/record.go`** (header, package comment: a record is one entry of a log, whatever kind of log it came from; `Reader` is the plug point for kinds of log). It holds the types above, as plain data, with these meanings in comments:
  - `Stamp.State`: `NoStamp` (the reader found no time); `Resolved` (`Nanos` holds the time); `YearPending` (a stamp with no year: `Month`, `Day`, `NanoOfDay` hold it, and `Nanos` is not meaningful until the year is worked out).
  - `Stamp.Nanos`: nanoseconds since 1970. For a stamp with a zone it is the real instant. For a stamp with no zone it is the wall-clock reading carried as if it were UTC.
  - `Stamp.Exact`: true when the log states a zone or the stamp is a count since 1970. `Stamp.Zone`: the zone text exactly as written (`+02:00`, `Z`, `-0700`), empty when the log states none.
  - `Record.Source`: the number of the source in the run, from 1, set by the caller of the reader. `Line`: number of the first line, from 1. `Offset`, `Length`: bytes (call 9). `Raw`: the record's text.

package timeparse

import (
	"strings"
	"testing"
	"time"

	"github.com/ckir/aigolog/internal/record"
)

func wall(y int, mo time.Month, d, h, mi, s int) int64 {
	return time.Date(y, mo, d, h, mi, s, 0, time.UTC).UnixNano()
}

func layoutNamed(t *testing.T, name string) Layout {
	t.Helper()
	for _, l := range Layouts {
		if l.Name == name {
			return l
		}
	}
	t.Fatalf("no layout named %q", name)
	return Layout{}
}

func TestLayoutsAreTheNineOfTheDesignInOrder(t *testing.T) {
	var names []string
	for _, l := range Layouts {
		names = append(names, l.Name)
	}
	want := "rfc3339 iso-space-offset iso-space-offset-sp clf iso-t iso-space slash ctime syslog"
	if got := strings.Join(names, " "); got != want {
		t.Errorf("layout names = %q, want %q", got, want)
	}
}

func TestParseReadsEveryLayout(t *testing.T) {
	cases := []struct {
		layout string
		line   string
		want   record.Stamp
	}{
		{"rfc3339", "2026-01-05T10:00:01+02:00 sshd: x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 8, 0, 1), Exact: true, Zone: "+02:00"}},
		{"rfc3339", "2026-01-05T10:00:01.123Z sshd: x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 10, 0, 1) + 123e6, Exact: true, Zone: "Z"}},
		{"iso-space-offset", "2026-01-05 10:00:01+02:00 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 8, 0, 1), Exact: true, Zone: "+02:00"}},
		{"iso-space-offset-sp", "2026-01-05 10:00:01 -0700 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 17, 0, 1), Exact: true, Zone: "-0700"}},
		{"clf", `05/Jan/2026:10:00:01 +0200 "GET /"`, record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 8, 0, 1), Exact: true, Zone: "+0200"}},
		{"iso-t", "2026-01-05T10:00:01 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 10, 0, 1)}},
		{"iso-space", "2026-01-05 10:00:01,250 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 10, 0, 1) + 250e6}},
		{"slash", "2026/01/05 10:00:01 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 10, 0, 1)}},
		{"ctime", "Mon Jan  5 10:00:01 2026 x", record.Stamp{State: record.Resolved, Nanos: wall(2026, 1, 5, 10, 0, 1)}},

func TestParseFindsTheStampOnlyAtTheStart(t *testing.T) {
	l := layoutNamed(t, "iso-space")
	for _, line := range []string{"[2026-01-05 10:00:01] x", "(2026-01-05 10:00:01) x", "<34>2026-01-05 10:00:01 x"} {
		if _, ok := l.Parse(line); !ok {
			t.Errorf("Parse(%q) refused a stamp after a bracket or a priority tag", line)
		}
	}
	for _, line := range []string{" 2026-01-05 10:00:01 x", "\t2026-01-05 10:00:01 x", "at 2026-01-05 10:00:01", "x [2026-01-05 10:00:01]", "", "hello"} {
		if _, ok := l.Parse(line); ok {
			t.Errorf("Parse(%q) accepted a stamp that is not at the start", line)
		}
	}
}

func TestParseRefusesDatesThatDoNotExist(t *testing.T) {
	if _, ok := layoutNamed(t, "iso-space").Parse("2026-13-45 10:00:01 x"); ok {
		t.Error("month 13 was accepted")
	}
	if _, ok := layoutNamed(t, "syslog").Parse("Feb 30 10:00:01 x"); ok {
		t.Error("30 February was accepted")
	}
}

func TestParseDoesNotScanAHugeLine(t *testing.T) {
	line := strings.Repeat("x", 4<<20)
	l := layoutNamed(t, "iso-space")
	start := time.Now()
	for i := 0; i < 200; i++ {
		if _, ok := l.Parse(line); ok {
			t.Fatal("junk was accepted")
		}
	}
	if d := time.Since(start); d > 5*time.Second {
		t.Errorf("200 parses of a 4 MiB line took %v: the stamp must be looked for in the first bytes only", d)
	}
}

func TestDetectPicksTheLayoutThatFits(t *testing.T) {
	syslog := []string{"Jan  5 10:00:01 host a", "Jan  5 10:00:02 host b", "Jan  5 10:00:03 host c"}
	if l, ok := Detect(syslog); !ok || l.Name != "syslog" {
		t.Errorf("Detect(syslog lines) = %q, %v", l.Name, ok)
	}
	zoned := []string{"2026-01-05T10:00:01+02:00 a", "2026-01-05T10:00:02+02:00 b"}
	if l, ok := Detect(zoned); !ok || l.Name != "rfc3339" {
		t.Errorf("a zoned line also parses as iso-t, and the earlier layout must win: got %q, %v", l.Name, ok)
	}
}

func TestDetectIgnoresIndentedLines(t *testing.T) {
	lines := []string{
		"2026-01-05 10:00:01 ERROR boom",
		"\tat main.run(main.go:10)",
		"\tat main.main(main.go:5)",
		"    caused by: x",
		"2026-01-05 10:00:02 INFO ok",
	}
	if l, ok := Detect(lines); !ok || l.Name != "iso-space" {
		t.Errorf("a stack trace must not count against the layout: got %q, %v", l.Name, ok)
	}
}

func TestDetectNeedsHalfOfTheLinesToFit(t *testing.T) {
	lines := []string{"2026-01-05 10:00:01 a", "plain one", "plain two", "plain three"}
	if l, ok := Detect(lines); ok {
		t.Errorf("one stamped line in four fitted %q", l.Name)
	}
	if _, ok := Detect([]string{"plain", "text", "only"}); ok {
		t.Error("a layout was found in text with no stamps")
	}
	if _, ok := Detect(nil); ok {
		t.Error("a layout was found in no lines")
	}
}

- [ ] **Step 4: Implement**
  - `internal/timeparse/layouts.go`: `Layouts` is exactly these nine, in this order (name; Go layout; `Exact`; `YearPending`): `rfc3339` `2006-01-02T15:04:05Z07:00` exact; `iso-space-offset` `2006-01-02 15:04:05Z07:00` exact; `iso-space-offset-sp` `2006-01-02 15:04:05 -0700` exact; `clf` `02/Jan/2006:15:04:05 -0700` exact; `iso-t` `2006-01-02T15:04:05`; `iso-space` `2006-01-02 15:04:05`; `slash` `2006/01/02 15:04:05`; `ctime` `Mon Jan _2 15:04:05 2006`; `syslog` `Jan _2 15:04:05` year pending.
  - `(Layout).Parse(line)`: a line that begins with white space does not parse. Skip, at the start, one `<` digits `>` tag (one to three digits) and then one `[` or `(`, each optional and in that order. The stamp is then the longest prefix that `time.Parse` accepts with the layout, **looked for only within the first `len(layout)+40` bytes** (call: this bounds the work for a line of any length). Fractional seconds written with `.` or `,` are accepted (Go's parser does). A zoned layout gives `State: Resolved`, `Exact: true`, `Nanos` the real instant, `Zone` the zone text as written (the part of the matched text that the layout's zone field covers). An unzoned layout gives `Resolved` with `Nanos = WallNanos` of the parsed time and an empty `Zone`. `syslog` gives `YearPending` with `Month`, `Day` and `NanoOfDay` (nanoseconds since midnight, fraction included).
  - `Detect(lines)`: consider only the lines that are not blank and do not begin with a space or a tab, and only the first 100 of them. For each layout count the lines it parses. A layout fits if its count times two is at least the number of lines considered and its count is at least one. Return the fitting layout with the highest count, the earlier one in `Layouts` on a tie; `false` when none fits or there are no lines to consider.
  - `WallNanos(t time.Time) int64`: the nanoseconds since 1970 of `t`'s year, month, day, hour, minute, second and nanosecond read as UTC (the zone dropped).

### Task 4: The text reader

**Files:**
- Create: `internal/reader/text/text.go`, `internal/reader/text/decode.go`, `internal/reader/text/text_test.go`

**Interfaces:**
- Consumes: `record.Record`, `record.Stamp` (Task 2); `timeparse.Layout`, `timeparse.Detect`, `(Layout).Parse` (Task 2).
- Produces:
  - `text.SampleBytes = 64 << 10`; `text.SampleLines = 100`.
  - `text.NotTextError{Offset int64}` with `Error()` returning `input is not text: it holds a NUL byte at byte offset <Offset>`.
  - `text.New(r io.Reader) (*Reader, error)`; `(*Reader).Next() (record.Record, error)` (`io.EOF` at the end; `*NotTextError` if a NUL appears later); `(*Reader).Layout() (timeparse.Layout, bool)`; `(*Reader).Encoding() string` (`utf-8`, `utf-16le`, `utf-16be`); `(*Reader).Lines() int64`; `(*Reader).Bytes() int64` (bytes of the original input read so far).
  - `*Reader` implements `record.Reader`.

How it reads (the rules of design 7.1 "Text lines", with the calls of this plan):
- `New` looks at the first `SampleBytes` bytes without consuming them (`bufio.Reader.Peek`; the buffer is at least `SampleBytes` large). **`Peek` returns what it has together with `io.EOF` when the input is shorter than that, and nothing with `io.EOF` for an empty input (measured on 2026-11-16); neither is an error of `New`.** A byte-order mark `FF FE` means UTF-16 little-endian, `FE FF` UTF-16 big-endian, `EF BB BF` UTF-8 with a mark (the mark is skipped but counted in offsets). UTF-16 is decoded to UTF-8 by a reader of this package using `unicode/utf16`; **it reads from the same buffered reader, after the byte-order mark has been discarded from it, never from the original `io.Reader` (whose first block the buffer already holds)**. A lone surrogate becomes U+FFFD, and a stream that ends in the middle of a code unit (an odd number of bytes) ends with one U+FFFD. The rest of the rules then apply to the decoded text. A NUL byte in the sample of a stream that is not UTF-16 makes `New` return `*NotTextError`; a NUL found later makes `Next` return it.
- A line ends at `\n`; a `\r` immediately before it is not part of the line. A last line with no terminator is a line. A terminator at the very end does not start a further, empty line. A line may be of any length (read with `ReadSlice` in pieces).
- The sample for the layout is the lines of the first `SampleBytes` bytes (a last line cut by the end of the sample is not used), passed to `timeparse.Detect`.
- A line **starts a record** unless: it begins with a space or a tab, or it is blank, or a layout was found and the line does not parse with it. Such a line is joined to the record before it (its text added after a `\n`); when there is no record before it, it starts one.
- Invalid UTF-8 in a line is replaced with U+FFFD (`strings.ToValidUTF8(s, "\uFFFD")`); offsets and lengths still count the original bytes.
- The record's `Stamp` is the layout's parse of its first line, or `NoStamp`.

### Task 6: Retention: `List` and `Sweep`

**Files:**
- Create: `internal/store/retention.go`, `internal/store/retention_test.go`

**Interfaces:**
- Consumes: `store.Create`, `store.ParseName`, `tryLockFile`, `unlockFile` (Task 5).
- Produces: `store.Info{Path string; Created time.Time; Size int64; State string; Records int64; Version string}` (`State` is `complete`, `incomplete` or `running`; for `running`, `Records` is 0 and `Version` is empty because the database is not opened); `store.List(dir string) ([]Info, error)` (newest first; a missing folder gives an empty list); `store.Policy{All bool; MaxAge time.Duration; MaxTotalBytes int64; Now time.Time}`; `store.SweepResult{Removed, Kept, Running []Info}`; `store.Sweep(dir string, p Policy) (SweepResult, error)`; `store.DefaultDir() (string, error)` (`os.UserCacheDir()/aigolog`).

Rules of `Sweep` (design 7.4 and 7.12): for each `<name>.db` in `dir` that `ParseName` accepts, try the lock of `<name>.lock` (a database with no lock file is not held); if it is held, the database is **running** and is never touched. Otherwise: an incomplete database is removed; a complete one is removed when `p.All` or when it is older than `p.MaxAge` (the age is `p.Now` minus the time in its name); then, if the sizes of what remains (running and kept) add up to more than `p.MaxTotalBytes`, the oldest kept ones are removed until they do not, or none is left to remove (a running one is never removed to meet the limit). A `<name>.lock` whose base name `ParseName` accepts, with no `<name>.db`, that nobody holds is removed. Files whose names are not ours are left alone. A database's size is that of its `.db` file. Removal takes the lock first, deletes `.db` and `-journal`, closes the lock file, then deletes `.lock`. A file that is already gone (another cleaner got there first) is not an error. Any other error removing one database is kept and the sweep goes on; the errors come back joined (`errors.Join`) together with the result.

// harness runs a command with a private cache folder and no configuration file.
type harness struct {
	t     *testing.T
	cache string
	stdin string
	now   time.Time
}

func newHarness(t *testing.T) *harness {
	t.Helper()
	return &harness{t: t, cache: filepath.Join(t.TempDir(), "cache"), now: time.Date(2026, 2, 1, 12, 0, 0, 0, time.UTC)}
}

func (h *harness) run(args ...string) (code int, out, errOut string) {
	h.t.Helper()
	var o, e bytes.Buffer
	vars := map[string]string{"AIGOLOG_CACHE_DIR": h.cache, "AIGOLOG_CONFIG": filepath.Join(h.cache, "no-config.json")}
	code = RunEnv(Env{
		Stdin:     strings.NewReader(h.stdin),
		Stdout:    &o,
		Stderr:    &e,
		LookupEnv: func(k string) (string, bool) { v, ok := vars[k]; return v, ok },
		Now:       func() time.Time { return h.now },
		Zone:      time.UTC,
	}, args)
	return code, o.String(), e.String()
}

func (h *harness) file(name, body string) string {
	h.t.Helper()
	p := filepath.Join(h.t.TempDir(), name)
	if err := os.WriteFile(p, []byte(body), 0o600); err != nil {
		h.t.Fatal(err)
	}
	return p
}

func dbCount(t *testing.T, dir string) int {

func TestA2ACleanerThatRunsWhileAnAnalysisWorksRemovesNothingThatIsLive(t *testing.T) {
	h := newHarness(t)
	var big strings.Builder
	for i := 0; i < 60000; i++ {
		big.WriteString("plain line " + strings.Repeat("q", 80) + "\n")
	}
	f := h.file("big.log", big.String())
	done := make(chan struct{})
	var code int
	var out string
	go func() {
		code, out, _ = h.run("analyze", f)
		close(done)
	}()
	// wait until the run has made its lock file, then clean until it ends
	for {
		if m, _ := filepath.Glob(filepath.Join(h.cache, "*.lock")); len(m) > 0 {
			break
		}
		select {
		case <-done:
			t.Fatal("the analysis ended before the test could clean beside it")
		default:
			time.Sleep(time.Millisecond)
		}
	}
	metLive := false
	for running := true; running; {
		select {
		case <-done:
			running = false
		default:
			if _, cleaned, _ := h.run("clean"); strings.HasSuffix(strings.TrimSpace(cleaned), "running 1") {
				metLive = true
			}
		}
	}
	if code != exitcode.OK || !strings.Contains(out, "records 60000") {
		t.Errorf("the analysis was disturbed by a cleaner: code %d, output:\n%s", code, out)
	}
	if !metLive {
		t.Error("no cleaner ever met the live run, so this test proved nothing")
	}
}
